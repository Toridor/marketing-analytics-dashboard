О данных и методологии

Данные каналов вручную перенесены со скриншотов GA4 Demo Account (Google Merchandise Store), 22.10–18.11.2026. Итог GA4: 153 914 сеансов, сумма строк: 151 314 (расхождение 2 600). События purchase / сеансы — прокси, не доля сеансов с покупкой. Дневная динамика перенесена из отдельного отчёта GA4, но сумма ежедневных сеансов (150 862) не совпадает с общим итогом (153 914). Рекламных расходов и данных последовательной воронки нет. Импорт CSV/XLSX обрабатывается локально в браузере; данные не отправляются на сервер. Вложения не публикуются автоматически на GitHub.

DATA MANAGEMENT

Редактор и импорт данных

CSV / XLSX, редактирование таблицы и локальное сохранение

Изменения хранятся только в этом браузере. Чтобы обновить публичный сайт для всех, нужно загрузить файл данных в репозиторий.

Раскрыть таблицу каналов и изменить значения
ChannelSessionsLeadsPurchasesImpressionsClicksSpendRevenueNew customers

Поля для CSV/XLSX: channel, sessions, purchases (leads необязательно), impressions, clicks, spend, revenue, new_customers. Для ежедневной динамики отдельный лист/CSV с полями date, channel, sessions, purchases. Для воронки: stage, users (по одному этапу на строку). Отсутствующие рекламные поля показываются как «—», а не как нули.
